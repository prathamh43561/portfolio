# Pratham — Personal Portfolio

A responsive personal portfolio website built with **HTML, CSS, and JavaScript**. It introduces Pratham, highlights selected projects and skills, and provides contact and social links.

## Live Demo

After enabling GitHub Pages for this repository, add your published URL here:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Features

- Responsive layout for desktop, tablet, and mobile
- Introduction and About section
- Selected projects showcase
- Skills and interests section
- Contact call-to-action
- LinkedIn, GitHub, and Instagram links
- Dynamic copyright year
- No frameworks or build tools required

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code.

## Deploy with GitHub Pages

1. Push `index.html` to the `main` branch of your GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. Once deployment finishes, open the URL shown in the GitHub Pages section.

## Customize the Portfolio

Before publishing, update the placeholder details in `index.html`:

- Replace `your.email@example.com` with your email address.
- Replace the generic social links with your actual LinkedIn, GitHub, and Instagram profile URLs.
- Update project descriptions and add links to your real projects.
- Review the About and Skills sections so they accurately represent your experience.
- Add a profile photo or resume link if desired.
